# PetShop Front

Una aplicación web moderna para la gestión de una tienda de mascotas, desarrollada con Vue.js.

## 📋 Descripción

Este proyecto es la interfaz frontend de una plataforma de tienda de mascotas (petshop) que permite a los usuarios explorar, buscar y gestionar productos relacionados con mascotas. Ofrece una experiencia de usuario intuitiva y responsiva.

## 🛠️ Tecnologías Utilizadas

- **Vue.js** (84.8%) - Framework progresivo de JavaScript para construir interfaces de usuario
- **JavaScript** (13.4%) - Lógica de la aplicación
- **CSS** (1.4%) - Estilos y diseño responsivo
- **HTML** (0.4%) - Estructura de la aplicación

## 📦 Requisitos Previos

Antes de comenzar, asegúrate de tener instalado:

- **Node.js** (v14 o superior)
- **npm** o **yarn** como gestor de paquetes

## 🚀 Instalación y Configuración

### 1. Clonar el repositorio

```bash
git clone https://github.com/AngelAmador384/petshop-front.git
cd petshop-front
```

### 2. Instalar dependencias

```bash
npm install
# o si usas yarn
yarn install
```

### 3. Ejecutar la aplicación en desarrollo

```bash
npm run serve
# o si usas yarn
yarn serve
```

La aplicación se abrirá en `http://localhost:8080`

## 🏗️ Construir para Producción

```bash
npm run build
# o si usas yarn
yarn build
```

Los archivos optimizados se generarán en la carpeta `dist/`.
